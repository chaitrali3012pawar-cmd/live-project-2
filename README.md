
# World Bank Development Indicators – Data Analysis Project
Project Overview

This project focuses on analyzing World Bank Development Indicators to understand global trends in CO₂ emissions, GDP growth, population, and energy usage across countries and years. The goal was to clean raw data, perform exploratory analysis, and create an interactive dashboard for data-driven insights.
# Objectives

Analyze global development indicators across multiple countries

Identify trends in CO₂ emissions and economic growth

Build KPIs for comparison and decision-making

Create an interactive Power BI dashboard for stakeholders
# Dataset

Source: World Bank Open Data

Data Type: Structured (Excel / CSV)

Time Period: Multiple years

Countries: Global

# Data Cleaning & Processing

Removed null and duplicate records

Standardized country names and year formats

Filtered required indicators

Created calculated fields for analysis

Tools used:

Excel

SQL (MySQL)

#  Exploratory Data Analysis (EDA)

Trend analysis for CO₂ emissions by country

Comparison of GDP vs emissions

Identification of top and bottom performing countries

Year-wise growth analysis

# Key KPIs

Total CO₂ Emissions

Average GDP Growth

Emissions per Capita

Country-wise contribution

# Dashboard

Built an interactive Power BI dashboard

Filters by country and year

Visuals include line charts, bar charts, KPIs, and maps

# Tools & Technologies

Excel

SQL (MySQL)

Power BI

Git & GitHub

World Bank Open Data

# Key Insights

CO₂ emissions show a strong correlation with industrial growth

Developing countries show rising emission trends

Some countries show negative emissions due to data adjustments and offsets
